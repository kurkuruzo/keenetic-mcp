`clear-step-2026-11-15/` — весь прежний комплект: широкое описание приложения, ТЗ, задание агенту, браузерный прототип и версия Visualize. Сохранён для истории по просьбе пользователя, но **не является текущей спецификацией**.

Актуальная итерация: [два экрана приложения](../clear-step/README.md). Она учитывает суженный объём и согласованную механику: задачи выбираются из плана проекта в действия, оба экрана показывают одну запись.
