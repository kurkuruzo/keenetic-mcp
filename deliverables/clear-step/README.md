# Ясный шаг

Концепция личного приложения для компьютера и телефона по практикам книги Максима Дорофеева «Джедайские техники. Как воспитать свою обезьяну, опустошить инбокс и сберечь мыслетопливо».

Дата подготовки: 14 ноября 2026 года. Статус: проектное предложение и демонстрационный прототип, не готовый продукт. Пользователь подтвердил личное использование на компьютере и телефоне; название, стек и границы релизов предложены для старта разработки.

## Что открыть

1. [Прототип экранов](prototype/index.html) — открыть файл в браузере. Работает без установки и внешних ресурсов. На телефоне потребуется разместить эту папку на доступном статическом хостинге; синхронизации между устройствами у прототипа нет.
2. [Принципы и практики книги](01-method.md) — источник каждого существенного продуктового решения и границы интерпретации.
3. [Описание приложения](02-product.md) — назначение, сценарии, состав первой версии, развитие.
4. [Экраны и взаимодействия](03-screens.md) — состояния, переходы, адаптация для телефона.
5. [Техническое задание](04-spec.md) — сущности, правила, архитектура, синхронизация, критерии приёмки.
6. [Задание агенту-разработчику](05-agent-brief.md) — порядок реализации и условия готовности.

Дополнительно: `inline/clear-step.html` — автономный фрагмент для показа интерактивного прототипа через Visualize в разговоре. Он содержит переходы между экранами, захват мысли, разбор в несколько результатов, действия, проекты, фокус и обзоры. Это отдельная адаптация для встроенного просмотра; для обычного браузера используйте `prototype/index.html`. Состояние встроенного просмотра может сохраняться средствами клиента, но не является надёжным хранилищем личных задач.

## Как посмотреть прототип

Начните с «Сейчас», затем добавьте запись кнопкой «Записать мысль». Откройте «Входящие», сформулируйте действие и добавьте его в результаты разбора. Можно добавить несколько результатов разных типов, прежде чем завершить разбор. Затем вернитесь к действиям, откройте фокус, отметьте выполнение и пройдите обзор. В «Проектах» показана разница между ближайшим действием и справочным планом. В «Идеях» можно превратить замысел в проект.

Прототип хранит демонстрационные данные только в памяти вкладки; обновление страницы возвращает исходный пример. Об этом прямо написано в интерфейсе. Не используйте его как настоящее хранилище. Проверка синхронизации, аккаунта, резервных копий и фоновых напоминаний относится к будущей разработке.

## Источник и ограничения

Основа — приложенный пользователем EPUB, его оглавление, текст практических разделов и приложения. Ссылки на источник даны по номерам разделов: номера страниц EPUB зависят от устройства. Это продуктовый синтез, а не перепечатка и не научная проверка утверждений автора. Название приложения не подразумевает сотрудничества с автором.

Исходный EPUB и извлечённый текст не включаются в поставку и Git. Папка самостоятельна и не меняет сервер Keenetic MCP; для реализации приложения следует завести отдельный репозиторий.

## Проверка поставки

JavaScript проверяется командой `node --check deliverables/clear-step/prototype/app.js`. Локальные ссылки документов и наличие ресурсов HTML проверяются отдельно. Это проверка комплекта, не функциональная приёмка приложения.

Автоматическое открытие локального `file://`-прототипа для визуальной проверки заблокировано политикой браузерного инструмента. Поэтому скриншоты и подтверждение пройденного браузерного сценария в поставку не включены. Вёрстка содержит адаптивные правила для телефона и компьютера; фактическая визуальная проверка остаётся необходимой перед принятием дизайна. Условия A01–A23 в ТЗ — будущие проверки продукта, они не заявлены пройденными на макете.
